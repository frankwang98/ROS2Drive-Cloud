# iov_monitor 展示能力整合

车队只读大屏已迁入 ROS2Drive-Cloud 的 `site/monitor.html`，控制台首页提供入口。演示无需后端；连接模式读取 `GET /api/v1/robots/fleet-snapshot`，每 2 秒刷新。

## 已吸收的内容

参考 iov_monitor 的设备统计、告警面板、总览大屏思路，实现在线/离线、执行中任务、任务进度、活跃故障与本次会话在线趋势。前端沿用 Cloud 的原生静态技术栈，没有引入第二套 Vue/Express 应用，也没有复制旧项目地图、装饰图片或第三方组件。

统一快照合并 registry 与 typed-only 车辆，按后端接收时间判断连接（10 秒超时）。运行、位置、故障和规划轨迹以 5 秒新鲜度显示；过期或未上报字段为未知。后端失败时不把缓存当实时数据，也不产生成功趋势采样。统计变化仅限本次页面会话，最多保留 90 次采样与 60 条事件。

位置图只显示选中车辆自身坐标系，避免将矿区、港口或其他地图坐标强行叠加。黄线是已上报的有效规划轨迹，绿线为位置轨迹。当前未添加多场景坐标转换。

## 没有迁入

旧 Express 后端、示例密码登录、WebSocket 回显、行政区地图和模拟交通灯/环境数据。旧登录不构成真实鉴权。现有后端依然面向受信网络；上线公网前须完成鉴权、TLS 和访问控制。

本次没有增加数据库；后端数据仍驻留内存，重启后丢失。真实告警历史、任务完成趋势、持久化和账户体系后续按实际需求开发。

## 使用

- Pages：打开控制台首页，点击“车队监控”。默认是明确标注的演示数据。
- 本地：使用现有 Cloud 启动流程，访问 `http://localhost:8000/dashboard/monitor.html`，切换连接后端并填写 `http://localhost:8000`。
- Pages 在线模式：输入可达 HTTPS 后端。需更新到包含 fleet-snapshot 的后端版本；旧版本会返回 404 并提示升级。
- 页面只发 GET 请求，不提供控制动作。
